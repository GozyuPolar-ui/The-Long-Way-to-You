# Target samples

The samples contains a collection of scenes, scripts, prefabs, and other assets to show how to use target indicators and as a starting point for customizing your own indicators.

The assets are grouped in three categories:

1. **Core Assets**

    Core assets contains the set of scripts, prefabs, and textures for you to use as a foundation for your own visual indicators.

2. **Example Assets**

    Example assets contains the scripts, prefabs, and other assets needed for the sample scenes.

3. **Scenes**

    Scenes that demonstrate using target indicators with the sample visual indicators. Use these to learn how to use the target indicators API.

> [!IMPORTANT]
> The **TextMeshPro Essentials** need to bee imported into your project for the text in the sample scenes to render. If you do not see text displayed in the samples scenes, you need to import the text mesh pro essentials. Navigate to **Window** > **TextMeshPro** > **Import TMP Essential Resources** and import.

Refer to the documentation to learn more about the [Samples](https://jakemanfre.github.io/target-indicators.github.io/manual/samples/samples.html).
